## 控制架构

- 采用级联控制: 位置 PD → 速度 PI → 电流 PI → PWM。
- 位置环使用 PD 而非 PI，因为 AS5048A 是绝对编码器，不会累积位置漂移。
- 位置 D 项使用滤波后的电机转速。
- 稳定目标值必须减去 IMU 零点偏移:

```text
target = -IMU_SIGN * (imu_pitch - imu_home_offset)
```

## 安全规范

- 刷写固件后不要直接开启 `G` 稳定模式。
- 必须先验证速度环和小角度位置环，再尝试 `G`。
- 机械结构变更后首次稳定测试必须使用 `GLIM5`。
- 执行 `H` 时，负载必须处于机械水平状态。

## 参数

当前保守的固件默认值:

```text
KP_POS = 1.0
KD_POS = 0.02
PLIM = 45 deg/s
DZ = 0.5 deg
STAB_LIM = 10 deg
```

首次稳定测试仍应显式发送:

```text
GLIM5
H
G
```

## 机械结构

- MPU6050 安装在固定底座/定子/支架侧。
- MPU6050 不得安装在转子臂、电机轴、负载或任何旋转部件上。
- AS5048A 安装在电机底部，作为电机角度传感器。
- 电机定子/背面固定在支架上。
- 转子臂连接到旋转输出侧。

## IMU 接口

- 当前固件使用软件 I2C 位操作（bit-bang）驱动 MPU6050。
- 当前软件 I2C 引脚: `PB5=SCL`, `PB4=SDA`。
- 不要假设当前 MPU6050 驱动需要 CubeMX 硬件 I2C1。

## 视觉模块

- 视觉模块不加入当前 Phase 1/2 开发计划。
- 项目分三个阶段推进:
  - **Phase 1**（当前）：基础自稳 — 机械装配 → 安全上电 → 调参 → G 模式稳定复现
  - **Phase 2**：完善打磨 — 调优 KP/KD/PLIM，量化性能指标，准备竞赛答辩
  - **Phase 3**（可选，有余力才做）：OpenMV 外挂视觉跟踪 — UART 通信 → 色块/人脸跟踪
- 原则：先把核心自稳功能做完整、做稳定，竞赛评委更看重"稳"而非"多"。
- 只有 Phase 1 + Phase 2 完全稳定后，才评估是否启动 Phase 3。
- 如果加视觉，推荐方案：外挂 OpenMV 通过 UART 与 STM32G431 通信，不占用主控资源。
